\begin{abstract}
Particle Swarm Optimization (PSO) performance is highly sensitive to the inertia weight parameter~$w$, which controls the balance between exploration and exploitation. Fuzzy logic controllers offer a promising approach for adaptive~$w$ adjustment based on population diversity and search progress. However, most studies focus on tuning membership functions while treating the rule base as fixed. In this work, we systematically analyze the impact of fuzzy rule base structure on PSO performance. Using a Mamdani fuzzy inference system with two inputs (diversity ratio, iteration progress) and one output (inertia weight), we define six semantically distinct rule base variants: baseline, exploitation-dominant, exploration-dominant, diversity-reactive, progress-dominant, and inverse. All variants share identical input and output membership functions, isolating the rule base as the sole variable. We evaluate all configurations at two granularity levels (3 and 5 linguistic labels) on a representative subset of the CEC~2017 benchmark suite with 31~independent runs per configuration. Statistical analysis using Wilcoxon tests and Friedman-Nemenyi post-hoc ranking reveals [PLACEHOLDER: key finding]. Our results provide practical guidelines for fuzzy rule base design in metaheuristic parameter control.

\subsection{Standard PSO Formulation}

The velocity and position update equations for PSO are:
\begin{equation}\label{eq:velocity}
v_i^{t+1} = w \cdot v_i^t + c_1 r_1 (p_i^t - x_i^t) + c_2 r_2 (g^t - x_i^t)
\end{equation}
\begin{equation}\label{eq:position}
x_i^{t+1} = x_i^t + v_i^{t+1}
\end{equation}

where $w$ is the inertia weight, $c_1$ and $c_2$ are acceleration coefficients, $r_1$ and $r_2$ are uniform random numbers in $[0,1]$, $p_i$ is the personal best, and $g$ is the global best.
