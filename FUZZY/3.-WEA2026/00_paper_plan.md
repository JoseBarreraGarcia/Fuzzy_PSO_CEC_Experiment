## 2. Research Question

> **How does the structure of the fuzzy rule base affect the performance of fuzzy-controlled PSO when input and output membership functions are held constant?**

### Sub-questions:
1. Is the rule base the most, or least, influential FIS component for PSO performance?
2. Do certain rule "strategies" (exploration-biased, exploitation-biased, diversity-reactive, progress-reactive) consistently outperform others?
3. Is performance sensitivity to rule structure problem-dependent (unimodal vs. multimodal vs. composition functions)?
4. Does granularity (3 vs 5 labels) amplify or attenuate the effect of rule base structure?
5. Can we identify "robust" rule bases that perform well across diverse problem landscapes?

## 3. Rule Base Variants to Test

### 3.0. Additive Factorial Design Rationale

With 3 input labels per variable × 3 output labels, each rule maps to {low, medium, high}, giving $3^9 = 19{,}683$ possible rule bases (3L) or $5^{25} \approx 2.98 \times 10^{17}$ (5L). Testing all is infeasible, and ad-hoc selection is arbitrary.

**Solution: Orthogonal factorial design** based on two semantic axes:

- **Axis 1 — Progress effect**: How does w change with iteration progress?
  - ↓ (decreasing): explore early, exploit late (classical PSO intuition)
  - ↑ (increasing): exploit early, explore late (anti-classical)
  - — (flat): no effect of progress

- **Axis 2 — Diversity effect**: How does w react to population diversity?
  - → (following): high diversity → high w (amplify current state)
  - ← (compensating): high diversity → low w (counteract current state)
  - — (flat): no effect of diversity

**Factorial combination (2×3 + 3×2 - 2×2 = 8 unique)**:

|                     | Div-agnostic (—) | Div-following (→) | Div-compensating (←) |
|---------------------|:-----------------:|:------------------:|:--------------------:|
| **Progress ↓ (H→L)**  | **R1**           | **R5**             | **R6**               |
| **Progress ↑ (L→H)**  | **R2**           | **R7**             | **R8**               |
| **Progress — (flat)** | *(constant, trivial)* | **R3**         | **R4**               |

Each rule is generated by an **additive model**, not hand-tuned:
- 3L: `output = clip(progress_effect + diversity_effect)` where effects ∈ {-1, 0, +1}, mapped to {low, medium, high}
- 5L: effects ∈ {-2, -1, 0, +1, +2}, mapped to {very_low, low, medium, high, very_high}
- Clipped to valid range

**Properties:**
1. Each mirror pair tests one axis inversion: R1↔R2, R3↔R4, R5↔R8, R6↔R7
2. R1–R4 isolate one factor → test "does progress/diversity matter?"
3. R5–R8 combine both factors → test interaction effects
4. All rules are formula-generated, not ad-hoc → reproducible, justifiable

**Design properties:**
- R1–R4 isolate **one factor** → main effect tests
- R5–R8 combine **both factors** → interaction tests

**Note:** R1 (progress-dominant, classical) and R5 (progress↓ + diversity-following) are the most likely to match PSO literature intuition. R2 and R7 represent deliberately counter-intuitive strategies as controls.

## 4. Experimental Design

### Fixed Components (Control Variables)
- **Input MFs:** I1 (Standard symmetric triangular)
- **Output MFs:** O1 (Shoulder triangular, normalized universe [0, 1])
- **Inference:** Mamdani (min-firing, max-aggregation)
- **Defuzzification:** Centroid (COG) with internal rescaling (see below)
- **wMin = 0.1, wMax = 0.9** (effective inertia weight range)

#### Centroid Rescaling for Fair Comparison

COG defuzzification inherently compresses the output: the centroid of any MF never reaches the universe extremes (0 or 1). The extreme centroids are:

- **3L (O1):** c_min = 0.167, c_max = 0.833
- **5L (O1):** c_min = 0.110, c_max = 0.890

Without correction, both granularities would produce **different effective w ranges** even with the same wMin/wMax configuration, making comparison unfair.

**Solution:** After defuzzification, `w_norm` is linearly rescaled from `[c_min, c_max]` → `[0, 1]`, then mapped to `[wMin, wMax]`. The bounds `c_min`, `c_max` are precomputed from the actual output MFs (`_compute_centroid_bounds()`), so they adapt automatically if the output set changes.

**Result:** Both 3L and 5L produce w ∈ [0.1, 0.9] exactly, enabling fair comparison.

**Paper note for plots:** Output MF figures show the normalized universe [0, 1] because that is where the MFs are defined. The rescaling to [0.1, 0.9] occurs after inference as a post-processing step. This should be noted in figure captions:

> *"Output membership functions are defined on a normalized universe [0, 1]. The defuzzified centroid is linearly rescaled to [0.1, 0.9] to compensate for COG compression."*

## 5. Statistical Analysis Plan

1. **Descriptive:** Mean, Std, CV%, IQR per (rule_variant × granularity, function)
2. **Non-parametric comparison:** Wilcoxon rank-sum test (paired, per function)
3. **Multiple comparison correction:** Holm-Bonferroni
4. **Effect size:** Cohen's d or Cliff's delta
5. **Ranking:** Friedman test + Nemenyi post-hoc (across all functions)
6. **By category:** Separate analysis for Unimodal / Multimodal / Composition
7. **Granularity effect:** Compare R_i-3L vs R_i-5L (does finer granularity amplify rule effects?)
