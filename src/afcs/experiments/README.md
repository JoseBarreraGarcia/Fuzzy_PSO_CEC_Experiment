# Experiments

Planificación de campañas, expansión de configuraciones, presupuestos,
ejecución, reanudación y ciclo de vida. Consume contratos de problemas,
optimizadores, controladores, métricas y persistencia.

El runner acepta una política de parámetros opcional y registra separadamente
configuración inicial, cambios efectivos y coste del control. No exige control
adaptativo para ejecutar PSO, GA u otra MH.

La futura política de semillas vivirá aquí, separada del ID autoincremental de
la base.

Estado: runner v2 pendiente; persistencia v2 disponible en
`afcs.persistence`.
