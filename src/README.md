# Código fuente v2

El código empaquetado de la nueva arquitectura vivirá bajo `src/afcs/`.
Actualmente esta estructura documenta responsabilidades y destinos; el código
heredado se migrará de manera incremental con pruebas y adaptadores explícitos.

No debe copiarse código antiguo aquí sin retirar o marcar claramente su versión
anterior, porque eso crearía dos fuentes de verdad.
