# Código fuente v2

El código empaquetado de la nueva arquitectura vive bajo `src/afcs/`. Ya contiene
contratos, CEC2017, PSO, control de parámetros, lógica difusa, métricas,
campañas y persistencia. Problemas de ingeniería, GA, análisis y parte de los
consumidores heredados se migrarán incrementalmente con pruebas y adaptadores
explícitos.

No debe copiarse código antiguo aquí sin retirar o marcar claramente su versión
anterior, porque eso crearía dos fuentes de verdad.
