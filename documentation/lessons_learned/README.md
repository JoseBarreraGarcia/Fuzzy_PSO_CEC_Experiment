# Lecciones aprendidas

Esta carpeta reúne conocimiento técnico estable extraído de experimentos y
artículos anteriores. No sustituye los documentos históricos: conserva las
conclusiones que deben guiar nuevas campañas sin obligar a mantener en v2 los
manuscritos, resultados y archivos editoriales completos.

## Documentos

- [`CEC2017.md`](CEC2017.md): correcciones, límites y validaciones necesarias
  para usar la suite CEC2017 incluida en el repositorio.
- [`EXPERIMENT_DATA_AND_ANALYSIS.md`](EXPERIMENT_DATA_AND_ANALYSIS.md): contrato
  aprobado para réplicas, métricas, base de datos y análisis jerárquico.

## Regla de trazabilidad

Cuando una lección procede de la campaña MDPI se conserva su fuente original
en:

- rama: `Solver_CEC_Fuzzy_PSO_ARTICULO_MDPI`;
- commit: `f8649134362f9a7b5e04f2f2bf032eb4b5938172`.

Los documentos de esta carpeta pueden evolucionar con v2. Los documentos de la
rama histórica no deben reescribirse para hacerlos coincidir retroactivamente
con el nuevo diseño.
