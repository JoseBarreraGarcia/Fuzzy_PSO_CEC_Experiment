## Changes Summary

### Problem Statement (Your Request)
You felt that results were presented in a disorganized way, with many useless graphs.
You wanted results at 3 distinct levels:

1. **LEVEL 1: Raw CSVs** for extracting data from the environment
2. **LEVEL 2: Aggregated** with tables (mean, max, min, std, CV%) and plots (boxplots, percentiles)
3. **LEVEL 3: Disaggregated** with per-instance (SCP41, SCP51, ...) and per-config (PSO_S4_STD_FCS:A, etc.) rankings

---

## Solution Implemented

### New Python Modules (in `analysis_modules/`)

#### 1. `level1_raw_data.py` (90 lines)
✅ Extracts experiments from database into structured CSVs
✅ Functions:
   - `extract_experiments_data()` → all runs
   - `extract_best_per_config()` → best per configuration
   - `extract_mh_configs_summary()` → what configs were tested
   - `extract_per_instance_per_mh()` → separate CSV per instance+MH pair
✅ Output: `Resultados/resumen/level1_raw/`
   - `scp_experiments_all_runs.csv` (all results)
   - `scp_best_per_config.csv` (no noise)
   - `mh_configs_summary.csv` (experiment design)
   - `scp_<instance>_<mh>.csv` (per pair)

#### 2. `level2_aggregated.py` (280 lines)
✅ Descriptive statistics:
   - `generate_descriptive_stats_by_mh()` → Mean, Std, CV%, IQR, Min, Max, Range
   - `generate_descriptive_stats_by_instance()` → Problem difficulty ranking
✅ LNCS-format plots (Times New Roman, 10pt, 300 dpi):
   - `plot_boxplot_by_mh()` → Box plot comparison
   - `plot_percentile_by_mh()` → P10, P25, P50, P75, P90 bars
   - `plot_violinplot_by_mh()` → Distribution shapes
   - `plot_boxplot_by_instance()` → Instance difficulty comparison
✅ Output: `Resultados/resumen/level2_aggregated/`
   - 2 CSV files with statistics
   - 4 PNG plots (publication-ready)

#### 3. `level3_disaggregated.py` (300 lines)
✅ Per-instance MH rankings:
   - `generate_instance_rankings()` → For each instance, rank all MH
   - Output: `instance_SCP41_ranking.csv`, `instance_SCP51_ranking.csv`, etc.
   - Shows: "Which MH is best for SCP41?"
✅ Per-config instance rankings:
   - `generate_config_rankings()` → For each MH config, rank all instances
   - Output: `config_PSO_S4_STD_ranking.csv`, `config_PSO_S4_STD_FCS-A_ranking.csv`, etc.
   - Shows: "Which instances is PSO_S4_STD good/bad at?"
✅ Best results summary:
   - `generate_best_results_by_instance_mh()` → Best config for each instance+MH
✅ Global top configs:
   - `generate_top_configs_global()` → Top 20 configurations overall
✅ Output: `Resultados/resumen/level3_disaggregated/` (1-N CSVs)

## Quick Usage

### Run Everything
```bash
python analisis.py
```
→ Creates all 3 levels automatically (~1-2 minutes)

### Check Specific Levels Manually
```python
# Level 1 only (fast, ~5 sec)
from analysis_modules import level1_raw_data
level1_raw_data.main(verbose=True)

# Level 2 only (plots, ~30 sec)
from analysis_modules import level2_aggregated
level2_aggregated.main(verbose=True)

# Level 3 only (rankings, ~60 sec)
from analysis_modules import level3_disaggregated
level3_disaggregated.main(verbose=True)
```
