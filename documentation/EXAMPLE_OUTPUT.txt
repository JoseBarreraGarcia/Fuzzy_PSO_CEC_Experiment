================================================================================
SUMMARY
================================================================================

When you run: python analisis.py

You get:

✓ LEVEL 1: 4-5 CSVs with raw data (for external analysis)
✓ LEVEL 2: 2 statistic CSVs + 4 publication-ready plots (for papers)
✓ LEVEL 3: 1 + (# instances + # configs) CSVs with detailed rankings

Total time: ~1-2 minutes for typical 1000-5000 experiment runs
Total size: ~100-200 MB (mostly PNG plots)

Everything organized in: Resultados/resumen/
  ├── level1_raw/
  ├── level2_aggregated/
  └── level3_disaggregated/
