¿Cómo generar los gráficos?
================================================================================

Opción 1: Script simple
  $ python generate_fuzzy_plots.py
  
  Genera todos los 8 gráficos en ~3 segundos

Opción 2: Desde Python
  from FUZZY.fuzzy_plots import generate_all_fuzzy_plots
  generate_all_fuzzy_plots(verbose=True)

Opción 3: Gráfico específico
  from FUZZY.fuzzy_plots import plot_fuzzy_output_w_set
  plot_fuzzy_output_w_set('A')  # Genera solo Set A

¿Qué muestra cada gráfico?
================================================================================

01_fuzzy_input_diversity.png
─────────────────────────
  INPUT: Diversity Ratio [0, 1]
    0 = Población convergida (sin exploración)
    1 = Población dispersa (máxima exploración)
  
  Fuzzy Sets:
    Low (0.0-0.4)    → Población convergida
    Medium (0.3-0.7) → Transición
    High (0.6-1.0)   → Población dispersa
  
  Para reportes: Mostrar cómo se interpreta el nivel de diversidad

02_fuzzy_input_progress.png
──────────────────────────
  INPUT: Iteration Progress [0, 1]
    0 = Inicio del algoritmo
    1 = Final del algoritmo
  
  Fuzzy Sets:
    Early (0.0-0.4)  → Fases tempranas
    Mid (0.3-0.7)    → Fase media
    Late (0.6-1.0)   → Fases finales
  
  Para reportes: Mostrar evolución temporal del control

03_fuzzy_output_w_set_*.png
───────────────────────────
  OUTPUT: Inertia Weight w [0.1, 0.9]
  
  Disponible para cada Set (A, B, C, D):
    Low w    → Explotación (búsqueda local)
    Medium w → Transición
    High w   → Exploración (búsqueda global)
  
  Diferencias entre Sets:
    Set A: Prefiere baja inertia (explotación)
    Set B: Balanceado
    Set C: Simétrico
    Set D: Muy baja inertia (máxima explotación)
  
  Para reportes: Explicar características de cada variante PSO_FCS

04_fuzzy_rules_heatmap.png
──────────────────────────
  BASE DE REGLAS MAMDANI 3×3
  
  Matriz:
             Early     Mid       Late
    Low    → Med w   Low w     Low w
    Medium → High w  Med w     Low w
    High   → High w  High w    Low w
  
  Interpretación:
    - Al inicio (Early):  Favorecer exploración (w alto)
    - En medio (Mid):     Según diversidad
    - Al final (Late):    Favorecer explotación (w bajo)
  
  Para reportes: Mostrar lógica del control fuzzy

05_fuzzy_w_sets_comparison.png
───────────────────────────────
  COMPARACIÓN: Todos los w_sets lado a lado
  
  Muestra:
    - Set A (izq-sup): Desplazado a baja inertia
    - Set B (der-sup): Balanceado
    - Set C (izq-inf): Simétrico
    - Set D (der-inf): Muy baja inertia
  
  Para reportes: Justificar elección de Set, comparar variants

Personalización
================================================================================

Si necesitas modificar los fuzzy sets:

1. Edita FUZZY/fuzzy_controller_w.py
   - Busca método _build_w_mfs()
   - Modifica W_SETS dict

2. Regenera los gráficos:
   $ python generate_fuzzy_plots.py

3. Los nuevos gráficos estarán en FUZZY/plots/

Ejemplo: Agregar Set E más exploratorio

  "E": {
      "high":   (0.75, 0.85, 0.95),  # Más alto
      "medium": (0.50, 0.60, 0.75),
      "low":    (0.15, 0.30, 0.45),
  },

Luego:
  $ python generate_fuzzy_plots.py
  → Se agrega automáticamente 03_fuzzy_output_w_set_E.png
  → Se actualiza 05_fuzzy_w_sets_comparison.png
